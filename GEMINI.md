# Project Mandates: ICT Autonomous Agent

## Foundational Methodologies
This project adheres to the following core frameworks. All agent actions must align with these standards.

### 1. Product Interrogation (GStack)
- **Directive**: Never initiate implementation without a Design Doc that has passed `CEO` and `ENG` reviews.
- **Office Hours**: Use forcing questions to challenge the scope and identify the "real pain" (e.g., why did the win rate drop to 13%?).

### 2. Engineering Rigor (Superpowers)
- **TDD First**: Every bug fix (like the logging bug) or feature must start with a reproduction or test case.
- **4-Phase Debugging**: Always Reproduce -> Isolate -> Fix -> Verify. No "guessing" at fixes.

### 3. Self-Evolution (OpenSpace)
- **Skill Capture**: Every successful trade analysis or market-capture pattern must be saved to the `mempalace` or `skills/` folder.
- **FIX Evolution**: When the API fails (like Nvidia NIM), the agent must proactively suggest and implement an alternative (e.g., Gemini Flash integration).

### 4. User Dialectic (Hermes)
- **Context Preservation**: Maintain a deep model of the project's state. The agent is not just a tool, but a "Brain" that grows with the project.

## Current Technical Standards
- **Architecture**: MTF (1h/15m/5m) ICT Directional Bias.
- **Persistence**: SQLite for trades, JSON for patterns (Mempalace).
- **Communication**: Explicit, high-signal, professional.
